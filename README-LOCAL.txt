STARR SAVERS - LOCAL SETUP (XAMPP)

UPDATING AN EXISTING SETUP
  Copy everything in this zip into C:\xampp\htdocs  (say Yes to replace files).
  Your database is untouched. Nothing else to do.

FIRST TIME
  1. Start Apache + MySQL in the XAMPP Control Panel.
  2. Copy everything in this zip into C:\xampp\htdocs
  3. phpMyAdmin -> New -> database name  starr_savers  -> utf8mb4_unicode_ci -> Create
     -> select it -> Import -> choose database.sql -> Import.
  4. Open http://localhost/
